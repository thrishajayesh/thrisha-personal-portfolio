# Thrisha Personal Portfolio

React.js practical examination project based on the provided question paper.

## Features
- Separate reusable Home, About, Contact, Header and Footer components
- React Router navigation
- Responsive professional UI
- Props / reusable project data
- useState and event handling
- Contact form validation for required fields, email and phone
- Success and error messages
- Clean CSS without external UI framework

## Run
```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually http://localhost:5173/

## Build
```bash
npm run build
```

## Before submission
Replace placeholder contact details and social links in:
- `src/pages/Contact.jsx`
- `src/components/Footer.jsx`

You can also replace the letter avatar in `src/pages/Home.jsx` with a real profile photo if desired.
